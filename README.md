# Galleria Deli

A sourced, multi-page presentation site for Galleria Deli in Lutherville-Timonium.
Read `kb/HANDOFF.md` for accepted implementation and release state, and `WORKFLOW.md` for local container commands.

The site uses the existing public phone for inquiries. It does not process orders, payments or customer submissions.

Branches: `main`, `derek-dev`, `abdul-dev`. The production address is https://galleriadeli.xsolutionsmd.com; personal previews are https://d-galleriadeli.xsolutionsmd.com and https://a-galleriadeli.xsolutionsmd.com. See [Oracle deployment](docs/ORACLE_DEPLOYMENT.md) for the independent release contract. Configured URLs alone do not prove a deployed revision; compare each uncached `/version.json` with its branch head.

Public company facts live in `kb/`. Original media/provenance and private delivery records stay outside this repository. Selected authorized production media will live with the app source.
